# FFM — Fast File Manager

Веб файловый менеджер, который по сути является оберткой над FTP. Идея в том, что пользователь заходит в веб файл-менеджер, вводит данные от FTP и получает доступ к своим файлам, согласно своим правам. Таким образом все заморочки с правами решаются и настраиваются один раз на стороне FTP-сервера. Я знаю, что есть Filestash, он хороший и удобный, и умеет все что надо. Кроме того, что… не умеет копировать и перемещать папки и файлы. Не умеет делать работу, которую файловый менеджер должен делать по умолчанию.

## Возможности

- Просмотр, создание, удаление папок/файлов
- Drag-and-drop загрузка
- Скачивание через браузер
- Move / Copy с подтверждением перезаписи
- Свойства файлов
- Тёмная/светлая тема (auto/light/dark)
- Многоязычность (i18n), автоопределение языка
- SessionStorage — авторизация, сортировка, тема сохраняются между F5
- Поддержка мобильных устройств
- Возможность разворачивания в standalone или в Docker
- Работа через реверс-прокси

## Технологии

Python 3.12+, FastAPI, uvicorn, websockets, ftplib (stdlib), Vanilla HTML/CSS/JS, Tailwind CSS, Font Awesome

## Быстрый старт

```bash
# Windows
python -m venv .venv
.venv\Scripts\activate

# Linux / macOS
# python -m venv .venv
# source .venv/bin/activate

pip install -r requirements.txt
uvicorn server.main:app --host 0.0.0.0 --port 8000
```

Открыть http://localhost:8000, ввести данные FTP-сервера.

## Docker

```bash
docker run -d --restart unless-stopped --name ffm -p 8000:8000 -v ./config:/app/config ghcr.io/serenitatis/ffm:stable
```

Конфиг `config/config.yaml` подключается volume'ом — правки на хосте применяются после обновления страницы в браузере.

### Сборка вручную

```bash
docker build -t ffm .
docker run -d --restart unless-stopped --name ffm -p 8000:8000 -v ./config:/app/config ffm
```

## Конфигурация

`config/config.yaml` — хост/порт/режим FTP по умолчанию и настройка названия приложения.
Если файла нет или поля host, port, passive пустые — от пользователя ожидается ввод соотвествующих данных.

### Пример файла

```yaml
backend: ftp # Используемый бэкэнд для работы с файлами. Пока только ftp, поэтому параметр опциональный.
host: "192.168.1.1" # Хост для подключения
port: 2121 # Свой порт для подключения по FTP
passive: true # Активация пассивного режима FTP
title: "Файл менеджер" # Собственный заголовок приложения 
```
